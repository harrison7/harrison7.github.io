Incremental game

Elementary

An incremental game about building a star in a glass flask: fuse elements, unlock upgrades, and fill the periodic table.

The 2026 version is a TypeScript / Svelte 5 / PixiJS (WebGL shaders) game for the web, with iOS and Android planned through Capacitor — mobile is not released yet. Harrison designed and directed it, working with Claude as a coding agent.

The original 2024 version was a solo project for BYU CS 260, built with React, Express, WebSockets, MongoDB, and AWS.

  • TypeScript
  • Svelte 5
  • PixiJS / WebGL
  • Capacitor
