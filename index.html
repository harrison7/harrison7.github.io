Full stack · TypeScript · Live prototype

booktrakd

Jan 2026 – Present

A Letterboxd-style social site for books. Readers log, rate and review what they read, keep a diary and reading list, import their Goodreads or StoryGraph history, and follow friends to see what they're reading. It's a solo project, currently a working prototype.

Its catalog of about 49,000 books and 800,000 editions is built from Open Library's data dumps by a Node.js import pipeline and job worker that normalize titles and authors, merge duplicate works and rank books by popularity. The site and its fully typed API live in one TypeScript monorepo. The API is tested with Vitest against a real Postgres schema running in memory, GitHub Actions runs CI, and the prototype is deployed on Vercel with Neon Postgres.

Game project

Elementary

An incremental game about building a star in a glass flask and collecting the periodic table. I first wrote it for a BYU course in 2024, and I'm now rebuilding it with AI assistance.

AI-assisted rebuild · In development

2026 rebuild

Oct 2026 – present

An AI-assisted rebuild I designed and directed. Every commit is co-authored with Claude, and I co-wrote the design docs. The player starts with an empty flask, adds hydrogen until it ignites, and then keeps the star fed, hot and contained as it fuses heavier elements. Each mechanic is based on a real nucleosynthesis process. Three acts are playable so far, covering six generations of stars.

2024 version

BYU CS 260 · Jan – Apr 2024

I wrote this version myself in JavaScript and React, with an Express backend, WebSockets, MongoDB for user accounts and bcrypt cookie authentication, deployed on AWS EC2. I wrote the element-fusion and upgrade mechanics and the element guide. The leaderboard came from the course's Simon template.

Features of the AI-assisted rebuild

  • H
    Engine-free game architectureGame rules are pure TypeScript with no DOM or rendering, so the same code runs the browser game and a Node simulator.
  • He
    Bot-driven balance simulatorHeadless bots play every act at thousands of times real speed and report milestone times against design targets, so the effect of each balance change is measured.
  • C
    60 fps on integrated graphicsSDF shaders, pooled particles and batched geometry keep per-frame JavaScript under 5 ms with about 20 draw calls on Intel UHD graphics. An auto quality setting steps down when frames run slow.
